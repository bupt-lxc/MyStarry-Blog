## 1. 目标与范围

网站主要用于求职，展示李星辰的个人背景、实习经历、技术方向和项目成果，并提供博客、旅行足迹与留言板。

优先复用原项目与现有依赖。新增代码集中在个人内容、项目卡片与详情布局，以及原留言板缺少的限流和管理删除功能。本轮不增加 CMS、用户注册、全文搜索或新的前端框架。

## 3. 视觉与现有主题的复用

默认组合使用现有 `yellow-theme` 与 `style-neon`，关闭自定义花边模式，使原生 Neon 卡片正常生效。

原项目 Neon 的背景为深色，黄色主题改变强调色，没有现成的浅色 Neon。本轮按用户最新的“使用原本自带切换、尽量不重新造轮子”要求，沿用原生背景，不新增独立浅色主题。黄色采用现有 `--primary-*` 变量；少量硬编码红色光晕、图标或按钮状态改为引用同一组变量，保证整体协调。

首次访问默认黄色 Neon。主题和样式仍由现有面板切换、localStorage 保存，切页与刷新后保持一致。对于旧预览站访问者，执行一次有版本标记的偏好迁移，切换到新默认；之后尊重其自行选择。初始 HTML 的主题应与客户端一致，避免先闪现黑红色。

沿用现有入场、切页、悬停与网格波纹特效；尊重减少动态效果设置。保留声音开关，文字提示中文化。中文字体使用系统回退，调整必要的行距和溢出，不引入远程字体依赖。

原作者旋转人物和行走小人移除，个人介绍使用用户 GitHub 静态头像。头像在构建材料中本地保存，加载失败时显示姓名缩略标记。移除原作者的个人社交账号、状态、头像及求赞提示；开源许可证与项目致谢保留在仓库中。

详情使用原 Astro 内容集合和 Markdown 渲染能力。每个项目独立 Markdown，配图与其内容通过相对路径关联。

## 7. 留言板

### 7.1 复用和持久化

恢复上游已有的留言表单、卡片、分页、回复和点赞交互，以及 Guestbook 表和 Drizzle 查询代码。将数据库地址配置为本地 SQLite 文件；不依赖 Turso 账号或 Netlify 缓存服务。取消 Netlify 专用缓存，新增、回复、删除后从数据库读取最新结果。

访客无需账号，可填写昵称、留言与可选个人链接。成功写入后立即展示；每页 10 条，最新留言在前。保留原有回复关系和点赞按钮，提交与错误提示中文化。

数据库存放在服务器本项目的独立数据目录，挂载到 Node 容器 `/data`，文件路径 `/data/guestbook.db`。初始化和版本化迁移可重复执行，不能清空已有留言。重建容器、更新静态资源与代码不删除数据；部署前使用 SQLite 一致性备份方式保存可恢复副本。

### 7.2 输入与限流

- 昵称去除首尾空格后 1—32 个字符；留言 1—1000 个字符；可选链接最多 200 个字符，只接受 HTTP／HTTPS。
- 普通留言按纯文本展示，保留换行；查询使用参数化操作。非法输入返回 400。
- 同一来源地址的留言／回复写入，每 60 秒最多 1 次，每小时最多 10 次；超限返回 429 和 Retry-After，表单保留未提交内容。
- 点赞同一留言在同一浏览器中只允许一次；同一来源地址每分钟最多 30 次点赞请求，超限返回 429。服务端校验访客标记和限流，不仅依赖按钮禁用。
- 限流状态存入持久化数据库，重启后仍有效；存储地址的带密钥摘要，清理过期记录，不对外公开来源地址。
- 仅信任本项目 Nginx 覆写后的来源地址；Node 服务不发布公网端口，不能靠伪造转发头绕过限流。
- 数据库不可用时返回 503 和中文提示，静态个人主页与作品集继续可访问。

### 7.3 管理删除

提供简洁的管理员登录与留言管理页，只支持查看、删除和退出，不增加注册或多角色系统。后台不进入公开导航与站点地图。

管理员凭据通过服务器环境文件注入，使用独立随机口令，不复用 SSH 密码，不写入前端或 Git。会话复用 Astro 服务端会话机制，30 分钟后过期，使用 HttpOnly、SameSite Cookie；HTTPS 下启用 Secure。

登录按来源地址每 15 分钟最多失败 5 次。删除接口验证有效管理员会话及同源请求，未授权返回 401／403；点击删除时由界面确认目标。删除主留言时在同一事务中删除其回复，随后更新列表与计数。退出后旧会话不能继续执行删除。

## 8. 部署架构

公开入口继续为 `http://81.70.231.92:8550/`，Compose 项目继续使用 `astro-bento`，服务器目录继续为 `/home/ubuntu/astro-bento-portfolio`。

现有本项目 Nginx 直接提供预渲染主页、作品集、博客、旅行页和静态资源；留言板、管理页及 API 反向代理到内部 Astro Node 服务。使用官方 `@astrojs/node` 适配器，其他内容页保持预渲染。初始资源限制为 Nginx 64 MiB、Node 192 MiB，部署验收时记录实际占用。

不修改或重启既有 awards-nginx、会议项目和芯片项目；保留原 80／443、8530、5340、8000 等服务。只调整本网站的 Compose 服务。保留旧发布和数据库备份，使网站代码与数据库都可以恢复。

域名备案期间继续使用 IP＋端口，并保留预览的 noindex。备案完成后的域名、证书与搜索收录切换是后续操作。SSH 凭据、后台口令、数据库、会话、备份和运行日志全部排除在 Git 之外。
