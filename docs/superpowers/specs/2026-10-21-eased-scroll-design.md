# 点击滚动与返回顶部设计

日期：2026-10-21（北京时间）

状态：用户明确要求点击后的加速再减速滚动及非顶部圆形置顶按钮。沿用本会话此前已授权的“写 SPEC 后直接写 plan 并以 subagent-driven 执行，不再询问”流程。

## 行为

- 普通页内锚点（能力导航、详情目录及同页关联章节）点击后采用缓入缓出曲线：起步慢、中段快、末段慢。目标间距保留现有 scroll-margin-top；距离较远的滚动稍长，总时长约 0.45–1.0 秒。
- 首次打开深链接、跨页面导航及浏览器前进/后退继续由 Astro 原有导航处理，不额外播放长距离动画。
- 滚轮、触摸、指针拖动、滚动键或新的导航可取消当前动画；重复点击以最新目标为准。
- 尊重系统 prefers-reduced-motion，启用时直接定位。JavaScript 不可用时保留真实锚点的浏览器默认行为。
- 普通点击（含键盘激活）增强；新标签、修饰键、下载、其他来源/路径/查询参数及不存在的目标均保留原行为。

## 圆形按钮

- 在现有右下角工具栏上方放置直径 44 CSS px 的圆形箭头按钮，中文可访问名称与提示均为“返回顶部”。保留原有样式和声音按钮的位置。
- 页面超过顶部 8 px 时显示，回到该范围时隐藏且不可聚焦。颜色、背景、边框随原有主题变量；始终保持圆形，不套用会将按钮变成像素边框的 chrome--ns。
- 点击使用同一滚动动画回到 0；完成后将键盘焦点带到页面主要内容，不留在已隐藏按钮上。
- 在共享布局提供这项能力；hideSoundToggle 仅控制现有样式/声音控件，不应阻止页面返回顶部。

## 实现边界

沿用现有 Motion 依赖及 reduced-motion 工具，不新增依赖，不启用全局 CSS smooth 或修改手动滚动。通过 Astro 公开 navigate API 管理锚点历史，避免手写不兼容的 history index。增强代码负责在导航定位后、下一次绘制前恢复起点并播放动画；同页导航不能触发整页遮罩。监听与动画在 Astro 生命周期中正确清理，取消后不得再次自动跳转或抢回焦点。

## 验证

行为测试覆盖时长范围、曲线的加速/减速、取消/重复启动、减少动态效果与定位边界；浏览器检查真实锚点最终位置、历史返回、圆形按钮的显示/隐藏和键盘焦点，以及桌面/手机和主题切换。现有测试、Astro check、生产构建与页面产物校验全部通过后合并 master 自动发布；继续使用 8550 并验证留言数据与既有项目保留。
