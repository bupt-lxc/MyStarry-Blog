## 项目背景

面向国际赛事的获奖信息查询与证书管理需求，为主办方和参赛个人、团体提供在线服务。系统支持按姓名、团体、年份等条件查询获奖记录，查看与下载证书，并通过管理后台维护赛事数据，服务范围覆盖中国大陆、香港，以及俄罗斯和东亚、欧洲等多个国家与地区。


## 工作内容

我独立负责需求梳理、前后端开发、数据库设计及上线运维，完成从业务功能到公网服务的完整交付。

- **打通查询与管理流程**：基于 Vue 3 与 Go／Gin 开发公开查询端和管理后台，支持个人及团体获奖查询、证书查看下载、记录批量录入与维护，让赛事数据录入后能够直接用于对外查询。

- **完成公网部署与资源分发**：完成域名备案及部署，配置 Nginx 负载均衡、CDN 与对象存储，分别承接业务请求和证书等静态资源访问，支撑多地区用户使用。

- **支撑持续运行与维护**：实现管理员身份认证、数据统计及运行监控，配合证书图片按需加载，兼顾日常数据维护和页面访问体验，并持续承担上线后的维护工作。


## 效果与落地

约 2 个月完成开发，已落地使用 **6 个月**，累计使用人数 **超过 1,100 人**，录入信息 **1,400+ 条**。


## 核心技术

Go · Gin · GORM · MySQL · Vue 3 · Ant Design Vue · Nginx · CDN · 对象存储
